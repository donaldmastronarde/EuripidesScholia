Release4xml.zip contains the XML-related files:

  • OrestesScholia_2026.xml
  • PhoenScholia_2026.xml
  • teiScholiaSchema2026.rng is the Relax NG schema file for the preceding.
  • scholiaAll2026.xsl is the file for XSLT processing to produce HTML of the complete set of scholia of Orestes along with the arguments.
  • scholiaExegOnly2026.xsl is the file for XSLT processing to produce HTML of all the scholia of Orestes of subtype ‘exeg’ (that is, eliminating paraphrases, glosses, and any other subtypes).
  • scholiaGlossOnly2026.xsl is the file for XSLT processing to produce HTML of the glosses alone of Orestes, without the exegetic and paraphrase scholia.
  • scholiaMosch2026.xsl is the file for XSLT processing to produce HTML of the Moschopulean scholia of Orestes (with the few Planudean included).
  • scholiaMoschThomTri2026.xsl is the file for XSLT processing to produce HTML of the Moschopulean (and Planudean), Thoman, and Triclinian scholia of Orestes.
  • scholiaNoGloss2026.xsl is the file for XSLT processing to produce HTML of the set excluding glosses of Orestes of all types (also excluded are diagrams and word order annotations).
  • scholiaRec2026.xsl is the file for XSLT processing to produce HTML of the set excluding the old scholia (those of type ‘vet’) of Orestes.
  • scholiaThom2026.xsl is the file for XSLT processing to produce HTML of the Thoman scholia of Orestes.
  • scholiaTri2026.xsl is the file for XSLT processing to produce HTML of the Triclinian scholia of Orestes.
  • scholiaVetOnly2026.xsl is the file for XSLT processing to produce HTML of the old scholia of Orestes.
  • scholiaAll2026Ph.xsl is the file for XSLT processing to produce HTML of the complete set of scholia of Phoenissae along with the arguments.
